# Repository Map

This map covers every project-owned source/configuration file and every generated artifact family. Dependency directories, Python caches, test caches, and compiled frontend output are build products rather than authored project context.

## Root

| Path | Purpose |
|---|---|
| `README.md` | Quick-start, high-level algorithms, limits, API summary, validation commands, and judge-facing panel mapping. |
| `.gitignore` | Excludes virtual environments, caches, dependencies, compiled frontend output, generated RF suites, temporary jobs, logs, environment files, and TypeScript build metadata. |
| `docs/` | Structured project knowledge base indexed by `docs/README.md`. |
| `test-audio/` | Human-audible synthetic WAV fixtures, measured outputs, instructions, and distributable ZIP. |

## Backend packages

| Path | Responsibility | Direct project dependencies |
|---|---|---|
| `backend/__init__.py` | Marks `backend` as a Python package. | None. |
| `backend/api/__init__.py` | Marks the API directory as a Python package. | None. |
| `backend/pipeline/__init__.py` | Marks the pipeline directory as a Python package. | None. |
| `backend/api/main.py` | FastAPI app, CORS, upload limits/spooling, compute lock, asynchronous job executor, job retention, demos, visualization/layer/audio/envelope/export endpoints. | All pipeline modules, FastAPI, Starlette, NumPy. |
| `backend/pipeline/ingest.py` | `Capture`, WAV disambiguation, byte-based IQ/WAV ingestion, strict input validation. | `sigmf_io.py`, NumPy, SciPy. |
| `backend/pipeline/sigmf_io.py` | Datatype table, byte decoding, SigMF validation, standards-shaped annotation export. | NumPy, SigMF. |
| `backend/pipeline/detect.py` | Bounded Welch/STFT detector, band isolation, pulse envelope, confidence, logs, `DetectionResult`. | NumPy, SciPy. |
| `backend/pipeline/large_capture.py` | `DiskSamples`, memory-mapped/header-aware opening, overlapping-block analysis, track merge, bounded overview, bounded layer extraction. | `ingest.py`, `sigmf_io.py`, `detect.py`, `layers.py`. |
| `backend/pipeline/layers.py` | Waveform peak pooling, spectral gate, WAV and IQ Detect-stage layer construction, browser WAV generation. | `detect.py`, NumPy, SciPy. |
| `backend/pipeline/synth_gen.py` | Deterministic BPSK/QPSK/FM/pulse/noise generator; SigMF/truth writer; bundled demo source. | NumPy, SciPy. |
| `backend/make_audio_test_pack.py` | Generates five PCM16 WAV fixtures, reruns saved files through Detect, asserts expected results, writes documentation/ZIP. | Ingest and Detect pipeline. |
| `backend/validate.py` | Runs the current detector against the RF synthetic matrix and writes measured JSON. | Generator, ingest, detector. |

| Path | Purpose |
|---|---|

## Backend tests

| Path | Coverage |
|---|---|
| `backend/tests/test_detect.py` | 12 signal/SNR recall cases, bounds/timing tolerance, pulse width/PRI/count, ten noise seeds, adaptive scale invariance, fixed-debug agreement, malformed raw input, suite round trip, short single bursts, and continuous/non-pulse behavior. |
| `backend/tests/test_api.py` | Upload response contract, viewport spectrogram shape, layers, envelope, SigMF validation, actual differentiated WAV clips, quadrature/ambiguity choices, and invalid/missing resources. |

| `backend/tests/run_gib_check.py` | Opt-in Windows integration/measurement script. Generates and uploads a real 1 GiB file, polls it, measures backend working set, checks three distant bursts, spectrogram, and tail layers. It is not included in routine pytest collection. |

## Bundled data

| Path/pattern | Meaning |
|---|---|
| `backend/data/demo/demo.sigmf-data` | Four-second complex64 mixed BPSK/FM/pulse capture loaded by the IQ Demo API. |
| `backend/data/demo/demo.sigmf-meta` | Sample rate, datatype, version, description, and 100 MHz center-frequency metadata for the demo data. |
| `backend/data/demo/demo.truth.json` | Separate generator truth for the demo. The application does not read it. |
| `backend/data/demo/audio_demo.wav` | Two-second float32 real-audio tone/noise demo loaded by the Audio Demo API. |
| `backend/data/generated/{bpsk,qpsk,fm}_{20,10,0,-5}db.*` | Twelve two-second, 48 kHz SigMF fixture triplets: data, metadata, and truth. |
| `backend/data/generated/pulsed.*` | Two-second pulse fixture triplet. |
| `backend/data/generated/noise.*` | Two-second noise fixture triplet. |
| `backend/data/generated/demo.*` | Regenerated source copies of the mixed demo triplet. |
| `backend/data/generated/audio_demo.wav` | Regenerated source copy of the audio demo. |
| `backend/data/jobs/*.capture` | Temporary server-owned large uploads. Ignored by Git; deleted on failure/expiry/eviction, though abrupt server termination can leave recoverable cleanup work. |

The generated RF directory is ignored because it can be reproduced. The smaller `data/demo` set is intended to remain bundled.

## Third-party source boundary

`frontend/node_modules` contains third-party code and includes its own `AGENTS.md`; it does not govern project-authored files. The SCIFICN files under `frontend/src/components/ui` and its base stylesheet are copied third-party component source now living in the project. Their provenance is recorded in `frontend/THIRD_PARTY.md`. Generated WAV/IQ binary payloads are data artifacts and are described by their generators and truth/measurement files rather than duplicated byte-for-byte in Markdown.
